`layer.append(batch)` streams new features into an existing layer **without re-projecting
the features already on screen** — the key to live data like species occurrences. Each
example keeps its own retained GeoJSON array alongside the layer, so **Randomize colors**
recolors the data already drawn (via `recolor()`). Use **Stream** to pause/resume,
**Batch size** to control how many features each tick emits, **Rate** for an artificial
per-batch delay (mirroring loading from a file), and **Restart** for a fresh stream.

The source (`makeStreamingPoints` / `makeStreamingPolygons` in `shared/geo-data.ts`) is an
async generator that yields batches lazily up to 10M, so nothing is materialized up front.

> Append currently re-uploads the whole layer buffer per batch on WebGL (correct, but
> O(total)/batch), so very high point counts get heavy — the perf readout shows it. A
> follow-up adds true O(new) GPU sub-buffer uploads.
