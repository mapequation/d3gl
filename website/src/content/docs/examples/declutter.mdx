A scatter of labelled nodes that thins itself out when the view gets crowded. Each node is a
constant-pixel circle with a name label beside it; importance drives the radius, the color, and
the priority. **Scroll to zoom, drag to pan** — zoom **out** and the anchors crowd together, so
low-priority circles and overlapping labels drop out; zoom back **in** and they return. The
**Declutter** slider is the literal collision radius in pixels (0 turns it off); the **Nodes**
slider grows the cloud up to ~262k to stress the per-zoom collision pass.

## How it works

Two independent collision systems run on every zoom/pan, both in **screen space** — they compare
on-screen pixel distances, so what survives depends on the current zoom, not the data extent:

- **Glyph declutter** is built into [`plot`](/d3gl/reference/map/classes/plot/). A layer with an
  `anchor` and `sizeMode: "screen"` can set `declutter: <px>`; after each transform the engine
  hides any anchored glyph whose anchor lands within `<px>` of an already-kept one. It only
  toggles visibility flags — no geometry is rebuilt — so it is cheap enough to run on every
  zoom frame.
- **Label culling** is engine-owned via [`chart.labels`](/d3gl/reference/map/interfaces/datalabeloptions/).
  You give it the data plus `labelOf`/`anchorOf`/`importanceOf` accessors; the engine measures each
  label's text once, maps anchors through the transform, drops labels outside the viewport, then
  places the rest in importance order, skipping any whose box overlaps one already placed. Placed
  boxes go into a uniform screen grid, so each candidate is only tested against its neighbours and
  the pass stays linear in the number of labels in view. Only the surviving labels reach the DOM (an
  HTML overlay on WebGL; native `<text>`/`fillText` on SVG/Canvas, so they survive
  `toSVG()`/`toPNG()` export).

```ts
chart.layer("nodes", nodes, {
  draw: (ctx, d) => { ctx.arc(d.x, d.y, d.radius, 0, 2 * Math.PI); ctx.closePath(); },
  anchor: (d) => [d.x, d.y],   // pin each node in world coords
  sizeMode: "screen",          // constant pixel size — declutter needs screen space
  declutter: 30,               // hide anchored glyphs within 30 px of a kept one
  // ...fill, stroke, hover, tooltip
});
```

## Prioritizing what survives

The two systems express priority differently, so keep them consistent:

- **Glyphs** break ties by **input order** — the engine keeps the earliest-listed glyph of an
  overlapping group. Sort the data by importance descending and the big nodes win:

  ```ts
  const nodes = makeNodes(count).sort((a, b) => b.importance - a.importance);
  ```

- **Labels** take an `importanceOf` accessor (higher wins; ties fall back to input order). Set it
  from the same channel as the glyph order:

  ```ts
  chart.labels(nodes, {
    labelOf: (d) => d.label,
    anchorOf: (d) => [d.x, d.y],
    importanceOf: (d) => d.importance, // higher importance survives a collision
    offset: (d) => [d.radius + 4, 0],  // sit just past the circle's right edge
  });
  ```

The `offset` is a constant pixel gap applied to both the rendered position **and** the collision
box, so the label stays a fixed distance from its node at any zoom and culling reflects where the
label actually sits. The engine measures each label's text (no metric estimates) and centres it
vertically on the anchor, so the offset only needs the horizontal gap.

## A million points

The scatter above draws each circle as a tessellated `ctx.arc` **path** so it can carry an
`anchor` for declutter — but a path circle is tens of vertices, so the geometry gets heavy past a
few hundred thousand. For large clouds, use **analytic points** instead: `chart.points(...)`
draws each circle on the GPU from a single quad (~4 vertices), and a point's **anchor defaults to
its own center**, so `declutter` works with no extra wiring. That lifts the **Nodes** slider to
~1M on the same per-zoom cull.

This example drops the labels (label placement reprojects every anchor per zoom and can't follow a
million nodes) and sets `pickable: false` (a per-point hit index would dwarf the geometry), so it's
a pure glyph-declutter stress test. Scroll to zoom — the deep zoom range lets the crowd fully resolve.

```ts
chart.points("nodes", points, {
  x: (d) => d.x, y: (d) => d.y,
  radius: (d) => d.radius,        // per-point radius, like the path version
  fill: (d) => color(d.importance),
  sizeMode: "screen",             // constant pixel size — declutter compares on-screen distances
  declutter: 30,                  // anchor defaults to each point's center; no explicit anchor
  pickable: false,                // skip the per-point hit index so ~1M stays lean
});
```
